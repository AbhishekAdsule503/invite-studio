# Open product decisions

Resolve before the relevant module is implemented:
1. Exact subscription plans, yearly prices, quotas and expiry/grace-period rules.
2. Whether guest count includes only the invitee or invitee plus companions.
3. Whether invitees can change IN/OUT response and until what deadline.
4. Whether RSVP link is unique per guest and what happens if an invitation is forwarded.
5. Supported invitation file types and maximum upload size.
6. Contact import support: browser contact picker, VCF, native mobile app, or combination.
7. Whether email/SMS are in MVP or later.
8. Supported languages at launch.
9. Data retention, export and account deletion rules.
10. Super Admin support access boundaries.
